# 🗳️ AI Voter Management System (Tyagi RTK)

An intelligent voter management system built with **Flask + SQLite + Python + HTML/CSS/JS**, designed for fast search, voter record handling, and digital election management.

---

## 🚀 Features

- 🔍 Smart voter search system
- 👤 Voter profile management
- 📊 Dashboard with statistics
- 🧾 CSV import support
- 📄 PDF blueprint generation
- 🗂️ SQLite database integration
- 🎨 Responsive UI (mobile + desktop)
- ⚡ Fast Flask backend

---

## 🛠️ Tech Stack

- Python (Flask)
- SQLite Database
- HTML5 / CSS3
- JavaScript
- Bootstrap (UI styling)
- Raspberry Pi Compatible

## ⚙️ Installation

```bash
# Clone repo
git clone https://github.com/rtk-anolegend/Ai-voter-system-tyagirtk.git

# Move into project
cd voter_management_system

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run app
python app.py
🌐 Run Server
http://127.0.0.1:5000
